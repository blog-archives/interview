对，需要区分 **首次生成** 和 **基于已有版本修改**。协调 Agent 再次调用时，应提供当前题解和修改意见，不能只把题面、标程重新发一遍。

## 题解 Agent 流程

```mermaid
flowchart TD
    A([接收本轮任务<br/>题面、当前标程<br/>已有题解与修改意见（如有）]) --> B{本轮任务是什么？}

    B -->|首次生成| C[根据题面与标程生成题解<br/>组织思路、算法说明<br/>正确性论证与复杂度分析]

    B -->|修改已有题解| D[结合原题解与修改意见<br/>识别需要修改的内容<br/>核对题面或标程是否也有变化]

    D --> E[针对性修订题解<br/>保留仍然适用的内容<br/>同步调整受影响的解释与论证]

    B -->|所需材料缺失| F[说明缺少的材料<br/>不将修改任务擅自改为重新生成]

    C --> G[整理本轮产物<br/>题解草稿、修改摘要<br/>以及疑点或待确认事项]
    E --> G

    G --> H([返回协调 Agent])
    F --> H
```

两种任务的输入可以这样约定：

| 任务 | 需要提供 |
|---|---|
| **首次生成** | 题面、当前标程、写作要求 |
| **后续修改** | 当前题面、当前标程、要修改的题解版本、本轮修改意见；若题面或标程变化，附变化说明 |

**以本轮任务明确区分生成和修改。** 即使是再次调用，也可能是在补充材料后继续首次生成；不能简单按调用次数判断。

这个约定也适用于题面、标程和数据 Agent：修改时携带原产物与意见，由对应 Agent 修订，再把新版本返回协调 Agent。
