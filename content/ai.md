## llm prompt memory tool 四个模块之间的依赖关系

- LLM 模块是大语言模型，负责理解和生成自然语言文本，是整个系统的核心推理组件。
- Memory 模块是存储系统，保存对话历史、用户偏好等上下文信息，让交互有连续性。
- Prompt 模块是提示构建器，把用户输入、Memory 的上下文整合成 LLM 能理解的结构化提示。
- Tool模块是外部工具调用层，包含搜索引擎、数据库查询等工具，当LLM需要外部数据时，由它执行具体操作并返回结果。

Memory 模块为 Prompt 模块提供历史对话或上下文信息，Prompt 模块结合用户当前输入和 Memory 的上下文生成完整的提示文本，然后将提示文本输入 LLM 模块，LLM 模块处理后生成响应。如果 LLM 判断需要外部信息，会调用 Tool 模块，Tool 模块执行后返回结果，结果会被 Prompt 模块用于生成新的提示，同时 Memory 模块会更新存储最新的交互信息。

## RAG 的原理

RAG 全称是 Retrieval-Augmented Generation，即检索增强生成。

它的核心是在 LLM 生成回答前，先从外部知识库检索相关信息，再把这些信息作为补充内容加入提示词，让 LLM 基于检索到的事实性数据生成回答，这样能提升回答的准确性和时效性。
